# Patient Monitoring & Disease Progression Dashboard

An AI/ML project for exploring patient vital signs, clustering physiological observations, dimensionality reduction, and hidden-state progression modeling.

## Features

- Patient vital-sign monitoring
- K-means and Gaussian Mixture Model (GMM) clustering
- PCA and Factor Analysis
- Ward hierarchical clustering comparison using Adjusted Rand Index
- Four-state Hidden Markov Model (HMM)
- Interactive dashboard built with Streamlit and Plotly

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- hmmlearn
- Streamlit
- Plotly

## Dataset

The project uses the PhysioNet Sepsis Prediction dataset. The dataset is not included in this repository. Follow the original dataset's access and usage terms.

## Disclaimer

This project is for educational and research purposes only. Model outputs are not medical diagnoses or validated clinical risk predictions.
